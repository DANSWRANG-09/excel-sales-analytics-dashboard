# 📊 Sales Performance Analytics Dashboard — Microsoft Excel

> **Interactive Excel data analytics project built for a Data Analyst portfolio**

An end-to-end **Sales Performance Analysis** project created in Microsoft Excel. The project transforms transaction-level sales data into a clean analytical workbook with **KPIs, regional analysis, category performance, product lookup, salesperson rankings, and visual dashboards**.

🔗 **[View the Live Project Page](https://danswrang-09.github.io/excel-sales-analytics-dashboard/)**  
📁 **[View the GitHub Repository](https://github.com/DANSWRANG-09/excel-sales-analytics-dashboard)**

---

## 🎯 Project Objective

The goal of this project is to demonstrate how Excel can be used to turn raw sales data into **actionable business insights**.

The analysis focuses on questions such as:

- How is overall sales performance trending?
- Which regions generate the most revenue?
- Which product categories perform best?
- Which products are contributing the most sales?
- Which salespeople are performing strongly?
- How do sales change month over month?

## 🗂️ Workbook Structure

The project is organized into three main sheets:

### 1. Raw Data

Contains **400 synthetic transaction records** with fields such as:

- Date
- Region
- Category
- Product
- Units Sold
- Price
- Salesperson
- Total Sales
- Month

The raw dataset is formatted as an **Excel Table**, making the analysis easier to maintain and update.

### 2. Analysis

Contains formula-driven analytical sections including:

- Sales by region
- Sales by category
- Product lookup tool
- Salesperson performance
- Salesperson ranking
- Supporting calculations used by the dashboard

### 3. Dashboard

A visual reporting page containing:

- KPI cards
- Sales by region chart
- Category performance chart
- Monthly sales trend
- Summary metrics

The dashboard is connected to the analysis layer rather than relying on hardcoded values.

## 📊 Key Analytical Areas

### Regional Analysis

Compare revenue performance across different regions to identify stronger and weaker markets.

### Product & Category Analysis

Evaluate product-level and category-level sales to identify high-performing areas.

### Salesperson Analysis

Rank salespeople based on sales performance and compare individual contribution.

### Time-Series Analysis

Analyze monthly sales trends to understand changes in performance over the year.

### Product Lookup

The **Product Lookup** feature allows users to enter a product name and retrieve its related sales information directly from the workbook.

## 🚀 How to Use the Project

1. Download **`Sales_Performance_Analysis.xlsx`** from this repository.
2. Open the workbook in **Microsoft Excel**.
3. Go to the **Analysis** sheet and try the Product Lookup feature.
4. Explore the **Dashboard** to review the KPIs and charts.
5. Modify or add records in the **Raw Data** sheet.
6. Recalculate the workbook to see the analysis update based on the changed data.

## 🧪 Dataset

The dataset is **synthetically generated** for portfolio and learning purposes. It represents realistic retail sales transactions across:

- **4 regions**
- **4 product categories**
- **6 salespeople**
- **FY2025 transaction data**
- **400 sales records**

No confidential or real company data is included.
